# Contributing to the monorepo

Use the root offline quickstart. Preserve the nine existing Robot Black Box package boundaries; keep optional GRC mapping changes inside the bridge/compatibility workspaces. Recording and offline verification must remain independent of an upstream installation or hosted service.

Add meaningful tests for signature/order/intake/auth/persistence changes. Preserve delivered signed bytes; publish new examples for changed contracts and label observed simulator outputs separately from fixtures and fault interventions. Report actual platform/test results and unknowns without certification claims.

Do not include private runtimes/keys/credentials/customer contexts, model weights or unlicensed artifacts. Contributions follow the existing MIT license; contributors must have the necessary rights. This preparation asserts no additional ownership assignment or contributor agreement. See SECURITY.md for private vulnerability reporting boundaries.
