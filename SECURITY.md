# Developer preview security

This preview is experimental incident evidence software. Its local signature and canonicalization protocol has not received an independent cryptographic/security audit. A signature authenticates recorded bytes relative to supplied keys; it does not certify source truth, organizational independence, physical safety or fitness for an aviation installation.

Use public synthetic or appropriately authorized redacted sources while evaluating. Private keys, credentials, runtime databases and customer evidence generated under .rbb must remain local. The loopback console is a local prototype, not an exposed production service. Do not bind it publicly without a separately reviewed deployment design.

For a suspected vulnerability, use a maintainer-provided private reporting channel. If none is configured, first request a private channel without disclosing exploit details or secrets in a public issue. This file does not promise a response time, bounty, supported version window or hosted monitoring service. Documentation and test limitations are in RELEASE-SCOPE.md.
