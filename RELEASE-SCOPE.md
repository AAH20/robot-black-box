# Standalone release scope

This is a standalone Robot Black Box monorepo candidate. GitHub owner/repository remains undecided; no illustrative destination is authorization. It replaces the previous additive GRC Claw developer-preview publication structure. No GitHub repository/branch/PR has been created and nothing has been uploaded.

Included: root package/lock and eleven private npm workspaces, nine existing Robot Black Box module boundaries, selected MIT GRC compatibility sources, offline scripts and 97 tests, authored public synthetic fixture markdown, public handover/capture/portable/simulation evidence, research docs, unchanged MIT license and root CI. The small fixture vault is authored synthetic test data, not an actual private context store.

Excluded: .git/history, original monorepo root configuration and unrelated packages/apps, private .rbb keys/credentials/databases/stores, customer contexts, model weights, installed dependencies/environments, advanced governance artifacts containing host paths inside hash-bound objects, 21 corresponding broader tests, audio/video/image binaries and private commercial/pricing drafts.

Four unbound portable process summaries are absolute-path-redacted projections. Original signed envelopes/manifests and bound artifact bytes remain unchanged. The original portable manifest remains 6fd0596ca965543f794984f0b25263cff1a5fd6ac9cccd53d814c3ce13129be5. Public trust/pins remain historical same-host demo snapshots, not independently enrolled identities or global latestness.

Workspace release metadata adds private:true without changing licensing. The two compatibility manifests describe the selected source subset and remove unused original development/dependency metadata; source implementations and upstream copyright remain unchanged. They are optional bridge sources, not a claim to ship every upstream GRC package. There are no registry dependencies.

Actual checked platform: Node22.23.0/macOSarm64. Root Linux CI is proposed and has not executed remotely; Windows is unverified. The 97 shipped tests are distinct from the broader118 source suite and upstream root framework result. The README root commands are supported; historical research docs may reference excluded optional runtimes.

No Git history accompanies the candidate. Whole upstream history is unaudited and is not proposed for export. Local scan reports, inventories, archive and publication proposal are retained outside the outgoing monorepo root. Exact GitHub destination, payload approval and maintainer contribution/fixture rights confirmation remain publication gates. No license change, live hardware or proprietary inference claim is introduced.
