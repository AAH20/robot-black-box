# Standalone release scope

This is a standalone Robot Black Box monorepo candidate. The approved public GitHub destination is https://github.com/AAH20/robot-black-box. It replaces the previous additive GRC Claw developer-preview publication structure. The sanitized standalone monorepo was published to main. No GRC Claw PR, npm publication or deployment was performed.

Included: root package/lock and twelve private npm workspaces, ten Robot Black Box module boundaries, selected MIT GRC compatibility sources, offline scripts and 99 tests, authored public synthetic fixture markdown, public handover/capture/portable/simulation evidence, research docs, unchanged MIT license and root CI. The tenth public boundary is an engine-neutral Iceberg projection/reconciliation contract; it does not ship a managed catalog, object store or streaming service. The small fixture vault is authored synthetic test data, not an actual private context store.

Excluded: .git/history, original monorepo root configuration and unrelated packages/apps, private .rbb keys/credentials/databases/stores, customer contexts, model weights, installed dependencies/environments, advanced governance artifacts containing host paths inside hash-bound objects, 21 corresponding broader tests, audio/video/image binaries and private commercial/pricing drafts.

Four unbound portable process summaries are absolute-path-redacted projections. Original signed envelopes/manifests and bound artifact bytes remain unchanged. The original portable manifest remains 6fd0596ca965543f794984f0b25263cff1a5fd6ac9cccd53d814c3ce13129be5. Public trust/pins remain historical same-host demo snapshots, not independently enrolled identities or global latestness.

Workspace release metadata adds private:true without changing licensing. The two compatibility manifests describe the selected source subset and remove unused original development/dependency metadata; source implementations and upstream copyright remain unchanged. They are optional bridge sources, not a claim to ship every upstream GRC package. There are no registry dependencies.

Current checked platform: Node22.23.0/macOSarm64 with 99 passing tests. The initial release [GitHub Linux CI](https://github.com/AAH20/robot-black-box/actions/runs/35362157716) passed installation, build, all 97 then-shipped tests, signed fault demo, portable verification and review. The current suite is distinct from the broader118 source suite and upstream root framework result. The README root commands are supported; historical research docs may reference excluded optional runtimes. Windows is unverified.

No Git history accompanies the candidate. Whole upstream history is unaudited and is not proposed for export. Local scan reports, inventories, archive and publication proposal are retained outside the outgoing monorepo root. The user explicitly approved the public destination and reviewed payload before publication. Contributor/fixture rights remain the maintainers’ responsibility for subsequent additions. No license change, live hardware or proprietary inference claim is introduced.
