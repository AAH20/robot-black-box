# Consolidated evidence review

Run `npm run review:robot-black-box -- examples/robot-black-box-review/executed/consolidated-review.json` from this repository. The command reads the fixed public synthetic evidence allowlist and recomputes the review. It does not ingest runs, renew grants, load private custody databases, start model inference or execute package-supplied code. Results are reproducible for the same sources and check time; generation time and expiry-dependent results change with the clock.

The report and console separate eight layers: signed integrity, execution-time authorization, capture quality, recovery trust, custody acceptance, backup receipt, reviewer revision floor and reviewer checkpoint. Historical receipt checks use their stated execution times. Present checks use report generation time, displayed above the cards. Expired capture profiles, recovery trust and checkpoints remain unknown for present use. Historical public enrollment snapshots do not establish current revocation status. Private backup bytes and current reviewer database contents are not inspected by this public review. There is no combined certification score.

Every card cites public source IDs, JSON pointers or exact signed approval/execution event IDs. The source inventory includes full source-file SHA-256 digests. Citation responses are bounded projections, rather than unrestricted filesystem reads. The transport manifest digest is obtained locally and is not an independently retained trust pin. Integrity findings are relative to the supplied historical public keys.

Start the local console with `npm run console:robot-black-box-review`. It uses the existing local demo service and credentials, without startup re-ingestion. Open http://127.0.0.1:4323, authenticate using an existing tenant-a reviewer, investigator or administrator credential, and select “Review evidence operations & aircraft gaps.” The review endpoints require tenant-a, investigation_review purpose and an allowed role; unauthorized origins, extra query parameters and unlisted source IDs are rejected. Changing credentials clears displayed evidence immediately, and requests made under an earlier credential cannot repopulate the new view.

The five aircraft comparison gaps cover physical survivability, equipment and installation qualification, live capture and calibration, independent custody/trust retention, and off-host recovery. Each identifies the next investment gate. These are software demo findings; aircraft equipment approval, installation approval and physical qualification are external work. See [AIRCRAFT-BLACK-BOX-COMPARISON.md](AIRCRAFT-BLACK-BOX-COMPARISON.md) for the sourced comparison.

Provenance labels distinguish synthetic data, locally executed checks, fixtures, unknown conditions and external work not demonstrated. Proprietary model, biometric and vendor fixtures in the broader demo do not imply those products were executed in this review. Existing narrated and caption-only videos are preserved; this milestone adds no new video or voice recording.

Validation: the complete local suite passed 115 tests. Four focused report/API tests cover recomputation, source bounds, authorization and comparison scope. Actual browser checks passed desktop and 390-pixel mobile rendering, eight cards, six capture cases, five investment gates, exact signed event citations, credential clearing and tenant-b denial. Browser errors and console output were empty on the final authorized flow. The saved browser verification record is unsigned local test evidence, not an independent attestation. Remote CI was not run.

Artifacts are in `examples/robot-black-box-review/executed`: consolidated-review.json, browser-verification.json, console-overview.png, aircraft-gaps.png and console-mobile.png. Regenerating the report is a read-only review of the source evidence; its JSON snapshot is an unsigned presentation artifact.

Observed passive MuJoCo sample capture now records 100 engine samples across three channels (300 baseline observations) through the existing signed recorder and witness. Dropped, duplicate and delayed-receipt derivatives fail diagnostics; out-of-order source offsets trigger the existing integrity rejection. All 118 local tests passed. Simulation/host clocks and file-mediated ingestion remain explicit, with no physical calibration or live-source claim. See [SIMULATION-CAPTURE.md](SIMULATION-CAPTURE.md).
