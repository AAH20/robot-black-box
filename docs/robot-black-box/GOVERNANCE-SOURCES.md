# Primary technical sources and interface decisions

Reviewed 2026-09-17. Runtime version assertions come from executed local package metadata and receipts; public documentation guides interface design, not proof of installed integration.

- [NVIDIA Isaac GR00T repository](https://github.com/NVIDIA/Isaac-GR00T) and [GR00T platform page](https://developer.nvidia.com/isaac/gr00t): VLA/model and embodiment metadata motivate receipt fields. The current repository identifies N1.7; this delivery uses `fixture-not-loaded-v1`, not a claimed executed NVIDIA revision. Model/asset license assertions remain separately reviewed declarations.
- [Isaac Lab documentation](https://isaac-sim.github.io/IsaacLab/main/index.html): simulator/embodiment provenance informs OSS twin receipts. No Isaac Lab/Sim API is called. Proprietary twin contract remains vendor-neutral because no vendor was specified.
- [Obsidian data storage](https://obsidian.md/help/Files%2Band%2Bfolders/How%2BObsidian%2Bstores%2Bdata): vault-compatible notes are local Markdown. This integration reads a separate marked synthetic filesystem vault, not Obsidian private data, plugins or Sync accounts.
- [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) and [Python reference](https://reference.langchain.com/python/langgraph/overview): actual workflow uses `StateGraph`, `interrupt`, `Command(resume=...)` and SQLite `SqliteSaver`, with a consistent thread ID. Installed versions are pinned in the isolated requirements inventory and actual pause/reopen/resume evidence is retained.
- [Cognee API reference](https://docs.cognee.ai/api-reference/introduction) and [add documentation](https://docs.cognee.ai/core-concepts/main-operations/legacy-operations/add): ingestion, processing and retrieval are distinct operations. No REST requests or cloud credentials are used. The installed official Cognee 1.5.4 wheel was inspected for actual Python `add`, `config.system_root_directory`, `config.data_root_directory`, `datasets.list_datasets` and `datasets.list_data` interfaces. The SDK's connection-test failure log documents `COGNEE_SKIP_CONNECTION_TEST=true`; installed source confirmed the option. Storage-only add remains failed, and graph fixtures are explicitly simulated.
- [Cognee published package](https://pypi.org/project/cognee/1.5.4/) and [LangGraph published package](https://pypi.org/project/langgraph/1.2.11/): exact versions installed here. Dependency inventories are captured by pip freeze, not asserted to be portable wheel hashes.

No jurisdiction-specific legal conclusion is derived from these technical sources. Biometric assessment/consent/legal-basis fields represent evidence declarations for human review. Actual deployment would require specified jurisdiction, vendor, use case, authorized data and independent review.
