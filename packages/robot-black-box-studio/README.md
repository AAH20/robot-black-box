# robot-black-box-studio

MIT local reviewer-studio reference implementation. It demonstrates synthetic
tenant isolation, purpose-bound evidence access, cited investigation notes,
holds, scoped deletion, audit chaining and a loopback-only console.

It is not the hosted commercial control plane: there is no enterprise identity,
external custody, multi-region ingestion, production retention guarantee,
billing, support SLA or customer data. See the [open-core boundary](../../OPEN-CORE-BOUNDARY.md),
[runnable guide](../../docs/robot-black-box/RUNNING.md) and
[trust profile](../../docs/robot-black-box/TRUST-PROFILE.md).
